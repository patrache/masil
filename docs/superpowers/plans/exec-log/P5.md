### 내 판단

- 내 판단: Task 1 의 탐지는 파일이 i18n 패키지를 들여올 때 쓰는 이름(별칭 포함)으로 `<이름>.For(…)`·`<이름>.KoT()` 를 찾는다. 패키지 변수 초기화식·`func init()` 본문 안이라도 함수 리터럴(`func(t *i18n.T) string { … }`) 속 호출은 나중에 불리므로 허용했다. 탐지 시험 입력은 `internal/i18n/testdata/pkglevel/pkglevel.go`(빌드·래칫 밖)에 두었다.
- 내 판단: 실행 중 언어 바꾸기는 `MASIL_LANG` 을 비우고 `Config=choice` 로 다시 정한다. 설계서 6.2 의 `MASIL_LANG > config` 는 시작할 때의 순서이고, 켜 둔 앱에서 사용자가 직접 고른 언어가 아무 일도 안 일어나면 안 되기 때문이다. `auto`·모르는 값은 OS 언어로, 닫힌 언어는 관문 대체로 간다.
- 내 판단: OS 언어 읽기(`i18n.DetectOS`, macOS 는 `defaults` 실행 최대 300ms)는 Update 안에서 돌므로 실행당 한 번만 하도록 `sync.OnceValue` 로 묶었다(`Model.detectOS`).
- 내 판단: 바꾼 언어가 지금 보이는 언어와 같으면(예: zh-Hans 가 닫혀 ko 로 대체) `LocaleChangedMsg` 를 뿌리지 않는다(From != To 일 때만). `Model.locale` 은 그래도 새 결정으로 갈아 둔다(Task 24 의 출처 표시용, `(*Model).Locale()`).
- 내 판단: 계획 Step 3 에 없지만 `applyLocale` 은 `Notifier.SetLocale` 도 부른다 — 시작 때 실효 언어가 OS 알림까지 정하는 것(model.go ⑦)과 같은 규칙. 이미 열린 실시간 소켓의 `Accept-Language` 는 다음 재연결부터 바뀐다(소켓을 일부러 다시 잇지 않음).
