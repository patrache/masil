## 리뷰 반영 (P0 review)

- 1a1f928 — `TestGeneratedFresh` 의 `-short` 건너뛰기를 없앴다(생성기 약 0.1초). CI 의 `go test -short ./...` 가 이제 생성 신선도를 본다. ci.yml 은 고치지 않았다.
- 0e51af1 — 짧은 형을 불렀는데 그 언어에 `short` 가 없으면, 긴 형으로 돌아가되 en 단수·복수 고르기는 그대로 한다(`SeatsShort(1)` = `1 seat`). ko 에 `short` 가 있는데 번역에 없으면 생성기가 `<키>: <언어> missing short` 경고를 낸다(실패 아님, 누락 번역과 같은 급).
- aea18f1 — 서로 다른 인자 이름이 같은 Go 인자 이름이 되면(`a__b`·`a_b` → `aB`, `a`·`a_` → `a`) 생성기 오류(`param name collision`).
- df132b5 — `-fmt` 다시 쓰기가 항목 바로 위 주석(빈 줄 없이 `[키]` 에 붙은 줄)을 그 키의 메모로 보존하고, 정렬할 때 키와 함께 옮긴다. 표 안 주석·값 뒤 주석·떨어진 주석은 말없이 지우지 않고 생성기 오류로 막는다(`comment inside [키]`·`comment after a value`). doc.go 에 규칙을 적었다.
- afef273 — 키맵 행 설명 필드 이름을 계약대로 `Desc` 로 바꿨다(`keys`·`helpKey` 는 그대로 — 계획은 `Desc` 만 키 지정 리터럴로 씀).
- 3880643 — CLI 의 모든 api 클라이언트에 `Accept-Language` 를 붙였다: `newClient(env, server, opts...)` 도우미로 `masil login` 과 저장 실패 뒤 정리 `Logout`, `masil logout` 이 실효 언어를 싣고, `masil admin` 은 한국어 고정이라 `ko` 를 싣는다.
- 6c3f0b3 — 데몬이 설정을 다시 읽을 때마다 언어도 다시 정한다. 바뀌면 `language changed` 로그를 남기고 다음 세션의 `Accept-Language` 에 반영한다. OS 언어(`MASIL_LANG`·`LANG`·macOS `defaults`)는 시작 때 한 번만 읽는다.
