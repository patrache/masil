# masil P5 — 0.1.4 다국어 이관 · README · 번역 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** F0(P0) 위에서 기존 한국어 문구 약 1,700개를 패키지 단위로 카탈로그로 옮기고(한국어 화면 무변화), 영어 README·언어 선택 UI·en/zh-Hans 카탈로그·언어별 골든·검수 장부를 만들어 9.4 출시 관문을 통과한 언어만 연다.

**Architecture:** 한 방향 래칫(`legacy_literals.txt`)이 패키지별 한글 리터럴 수를 줄이게만 하고, x-pseudo 영역 검사(`pseudo_pending.txt`)가 화면 영역별로 "카탈로그를 거치지 않은 문구"를 잡는다. 실행 중 언어 바꾸기는 `ui.SetLocaleMsg` → 루트 앱이 `ctx.T`/`ctx.Lang` 을 갈아 끼우고 `ui.LocaleChangedMsg` 를 뿌리는 한 경로뿐이며, 문구를 패키지 변수·`init()` 에 굳히는 것은 시험이 막는다. 언어 열기는 검수 장부·누락·래칫을 읽는 관문 시험이 통과해야만 가능하다.

**Tech Stack:** Go 1.26.6(`CGO_ENABLED=0`), `golang.org/x/text/language`(P0), `BurntSushi/toml`, Bubble Tea v2 / `internal/ui/uitest` 골든(`github.com/charmbracelet/x/exp/golden`, `make golden` = `-args -update`), 서버 TypeScript + vitest(`@cloudflare/vitest-pool-workers`, `server/test/helpers.ts`).

**Spec:** `docs/superpowers/specs/2026-11-09-masil-v0.1.4-i18n-design.md`(이하 i18n, 15절 포함) · `docs/superpowers/specs/2026-11-09-masil-v0.1.3-design.md`(3장 i18n 규칙, JX8·JX9·JX10, 끝의 "빌더 질문에 대한 결정").

## Global Constraints

- 언어: `ko`(원본) · `en` · `zh-Hans`. 개발용 `x-pseudo` 는 `MASIL_LANG=x-pseudo` 로만, 설정 목록에 없음. 언어 목록에는 언제나 자기 이름(`한국어`, `English`, `简体中文`).
- 대체 순서 `zh-Hans → en → ko`, `en → ko`. 닫힌 언어는 화면이 en 으로, en 도 닫혔으면 ko 로. `MASIL_LANG` 은 관문을 건너뛴다. `Accept-Language` 는 실효 언어.
- **이관 PR 은 한국어 골든을 하나도 바꾸지 않는다**(기준: v0.1.2 태그). 새 다국어 화면 PR(설정 언어 줄, 로그인 언어 줄, 팔레트 언어 명령, `daemon status` 언어 줄, 기존 사용자 안내 토스트)은 바뀐 골든을 PR 설명에 하나하나 적고 오너가 본다(i18n 15절 2번).
- 출시 순서 0.1.3 → 0.1.4. 0.1.3 바이너리는 ko 만 열림, 언어 UI 는 숨김(`i18n.Selectable()==false`). 0.1.4 는 0.1.3 영역(`tools`·`termpane`·`leetcode`·`lazygit`·`workspace`·`archcanvas`·`apitest`) 문구의 en·zh-Hans 도 담는다.
- 카탈로그 영역 파일(`internal/i18n/locales/<언어>/<영역>.toml`): `common`, `auth`, `chat`, `feed`, `fun`, `settings`, `shell`, `help`, `cli`, `daemon`, `errors`, `alerts`, `time` + 0.1.3 영역. `claude.toml` 없음.
- 키 이름: `snake_case`, `<화면>_<무엇>`(예: `spacesettings_title`). 생성 함수는 `t.<Area>.<CamelKey>(…)`. 생성 파일은 손대지 않고 원본 TOML 만 고친 뒤 `go generate ./internal/i18n`.
- D8: `{name}님` 붙여 쓰기, 사람 이름 뒤 조사는 고정(`이/은/을/과`). 그 밖은 조사 표시 `{x|이/가}` — ko 파일에서만. en·zh 에서는 '님'·존칭 대응어 없음.
- 말투: ko 해요체 · en 문장형 대문자, 버튼·라벨에 마침표 없음, 성별 대명사 없음 · zh-Hans `你`, 문장에 전각 `，。：`, 라벨 끝 문장부호 없음, 가운뎃점은 `·`(전각 `・` 금지).
- 문구에 스타일·ANSI·제어 문자·양방향 제어 문자(U+202A~202E, U+2066~2069)·탭 금지. 강조는 인자로 넘기고 코드가 스타일을 입힌다. 사용자 텍스트는 인자로만, 그리기 전 `textwidth.Sanitize`.
- 좁은 자리(초소형·위젯 탭, 상태줄 모드 이름·단축키 힌트, 버튼, 표 머리, 설정 줄 이름, 시간 표기)의 키는 `max` 필수, 넘치면 `short` 먼저, 그다음 `textwidth.Truncate`(`…`). 표 열 너비는 고정 숫자가 아니라 그 열 문구 중 가장 넓은 것.
- 보안 경고·확인 대화상자의 "무엇을 하는지" 문장·오류 핵심 문장은 `no_truncate = true`, 경고·법적·개인정보 설정 문구는 `legal = true`.
- 번역하지 않는 것: 슬래시 명령 이름(`/poll`), CLI 하위 명령, 키 이름(`enter`, `ctrl+k`), 제품 이름 masil, HTTP 메서드·상태 문구, LeetCode 제목·난이도 값, 사용자 글, `internal/admincli`(영구 한국어), 로그 문구(새 로그는 영어).
- 새 모듈 없음. 서버 계약은 더하기만. 배포·태그는 이 계획 밖(오너 건별 승인).
- 기본 채널: ko `일반`, en `general`, zh-Hans `综合`. 채널 이름 규칙에 U+4E00–U+9FFF, U+3400–U+4DBF 추가. handle 규칙 `^[a-z0-9_]{3,20}$` 그대로.

## Review Focus

1. **바꾼 뒤 남는 옛 언어** — 패키지 변수·`init()`·컴포넌트 안에 만들어 둔 문구(팔레트 제목, 키맵 도움말, 목록 행 캐시, 열린 오버레이)가 바꾼 뒤에도 한국어로 남아 한 화면에 섞인다. → Task 1 `TestNoPackageLevelCatalog`, Task 4 `TestPseudoAfterSwitch`.
2. **업그레이드 직후 데몬만 도는 기기** — 0.1.3 이하에서 쓰던 PC 에서 TUI 를 아직 안 켰는데 launchd 데몬이 `LANG` 없이 OS 언어(en)로 알림을 띄운다. 한국어여야 한다. → Task 23 `TestDaemonLocaleUpgradedBeforeTUI`.
3. **config 의 이상한 언어 값** — `language = "ja"`, `"EN"`, `"zh-Hant"`, `"x-pseudo"`, 닫힌 `"zh-Hans"` 에서 화면이 깨지거나 설정 줄이 패닉하거나 config 가 다시 쓰이면 안 된다. 모르는 값은 `auto` 로 보고, 닫힌 값은 실효 언어로 보이며, 파일은 그대로. → Task 23 `TestResolveConfigOddValues`, Task 24 `TestSettingsLanguageRowOddConfig`.
4. **번역 문구 속 적대적 사용자 값** — en·zh 템플릿 인자로 들어간 이름에 ANSI·양방향 문자·아주 긴 이름·띄어쓰기 없는 한자열이 있어도 테두리·폭이 지켜진다. → Task 27 `TestHostileScreensLocales`.
5. **언어 저장 실패** — `config.toml` 이 `ErrNotLoaded` 이거나 쓰기 금지 폴더일 때 바꾸기는 이번 실행에만 적용되고 안내가 뜨며, 입력 중이던 글·화면 상태를 잃지 않는다. → Task 24 `TestLanguageSwitchNotSaved`.
