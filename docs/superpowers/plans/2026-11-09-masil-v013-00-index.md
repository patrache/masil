```
v0.1.2 ──▶ dev/v0.1.3

  ③ P1 · P2 · P3 · P4  (병렬, 끝나는 순서대로 rebase → 머지)

       · Task 21 은 P0 1 뒤, P1 Task 17·P0 Task 31 보다 먼저
  ⑤ P0 Task 31 (통합·출시 준비: README 도구 절, 출시 기능 집합 켜기, 도움말·팔레트 목록 골든 갱신)   ← P1~P4 + P5 21 뒤
  ⑥ P5 3묶음(Task 17~19) · Task 23·24 · Task 25~28(검수·골든·관문)   ← ⑤ 뒤

```

- 줄기 사이 DAG 의 핵심 간선: P1~P4 ← P0 Task 18(도구 등록)·19(`ctx.ToolState`)·9a(팔레트 `Label`); P1·P2 ← P0 16a(`termpane.Launch`); P1·P4 ← P0 21·23(`ctx.Secrets`·`RegisterToolLogin`); P1·P3·P4 ← P0 24·25(카드); P3·P4 ← P0 27·30(CollabHub); P2 ← P0 8·26(alert·자리 파일·리미터).

- 한국어 골든은 ⑥ 의 관문(Task 28)에서 언어를 열 때만 바뀐다.

## 5. 빼는 순서 (일정이 밀릴 때)

설계서 7.3 그대로 — **뺄지는 오너 결정**이며 미리 실행하지 않는다.

1. **P3 Task 28 일일 도전**(선택 Task, 마지막) — 빼면 `arch.challenge` 팔레트·카드 `challenge` 칸이 `null` 로 남을 뿐 다른 Task 영향 없음.
