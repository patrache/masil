# masil v0.1.3 P1 — LeetCode 오늘의 문제 + lazygit 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** P0 공통 기반(termhost·도구 표면·secrets·카드·i18n F0) 위에 도구 `leet`(LeetCode 오늘의 문제 읽기·풀기·실행·제출·#daily 카드·연속 풀이·순위)와 도구 `git`(사용자가 설치한 lazygit 을 패널·화면 전환·tmux 팝업으로)을 만든다.

**Architecture:** UI 없는 순수 패키지 `internal/leetcode`(LeetCode GraphQL·실행·제출·캐시·자격증명), `internal/leetcode/htmldoc`(문제 HTML → 문서 블록), `internal/lazygit`(찾기·저장소·설정 덧씌움·인자)를 먼저 만들고, 그 위에 도구 화면 `internal/ui/leet`·`internal/ui/gittool` 을 `ui.RegisterTool` 로 붙인다. 서버는 LeetCode 를 절대 부르지 않고, 사실 정보·풀이 기록만 D1 표 4개에 두며, #daily 루트·풀이 카드는 P0 의 `kind:"card"`(type `leet.daily`·`leet.solve`, 서버만 만듦) 메시지로 기존 `message.*` 이벤트를 탄다.

**Tech Stack:** Go 1.26.6 · `charm.land/bubbletea/v2` v2.1.1 · `charm.land/lipgloss/v2` v2.0.6 · `charm.land/bubbles/v2` v2.2.1 · `github.com/charmbracelet/x/ansi` v0.11.9 · `github.com/ionut-t/goeditor` v0.19.0(P0 가 go.mod 에 고정) · 표준 `net/http`·`html`·`encoding/json`·`os/exec` · 서버: Hono 4.13.16 · zod 4.6.7 · vitest(`@cloudflare/vitest-pool-workers`) · D1.

**Spec:** `docs/superpowers/specs/2026-11-09-masil-v0.1.3-design.md` — 3장(전체 제약), 5장 JX4·JX5·JX7·JX9·JX13, A7.2·A7.5(접두키), A8.2·A8.3·A8.5, A9.1, **A10 전체**, **A11 전체**, 8.2 JA10~JA30, 끝 절 "빌더 질문에 대한 결정". 함께: `2026-11-09-masil-v0.1.4-i18n-design.md` 6.4.3(카탈로그 모양)·6.6(폭·`no_truncate`)·7.6·9.3(래칫)·10.3·15절. 계약: `docs/contract/api.md`(0.7·2·5·6), `data-model.md`(2·3), `client-architecture.md`(2.1·2.2·3.2·3.3·4.3.3), `events.md`(새 이벤트 없음 확인용).

## Review Focus

1. **카드·서버 응답에서 온 `slug`/`frontend_id` 가 경로·링크 재료가 될 때** (`../../.ssh/x`, `a b`, 대문자, 101자): 클라이언트는 그 카드를 "모르는 문제" 로 보이고 풀이 파일·링크를 만들지 않는다 — `TestSolutionPathRejectsHostileSlug`(Task 8), `TestDailyCardHostileSlug`(Task 23).
2. **LeetCode 가 JSON 대신 Cloudflare 확인 HTML(200 또는 403, `text/html`)을 돌려줄 때**: 파싱 오류로 죽지 않고 `ErrBlocked` → `LeetCode 가 지금 이 요청을 막고 있어요 · o 브라우저에서 제출`, 자동 재시도 없음 — `TestClassifyCloudflareHTML200`(Task 9), `TestRunBlockedShowsBrowserHint`(Task 21).
