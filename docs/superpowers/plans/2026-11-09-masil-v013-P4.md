# masil v0.1.3 P4 — API 시험 도구 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 다섯 번째 도구 `api`(🧪 API 시험)를 만든다 — 요청 만들기·보내기(내 PC 에서만), 응답 보기, 검사·추출, 실행기, 기록, curl·OpenAPI·Postman 가져오기/내보내기, 개인 컬렉션(로컬 파일)과 방 공유 컬렉션(CollabHub `apicol`), 결과 카드(`api.result`·`api.run`), 그리고 비밀값 다섯 겹 보호.

**Architecture:** UI 없는 순수 엔진 `internal/apitool`(모델·변수·전송·가드·검사·가리기·탐지·기록·실행기·공유 매핑·카드 데이터)과 변환기 `internal/apitool/convert` 를 먼저 시험만으로 완성하고, 그 위에 도구 표면 화면 `internal/ui/apitool` 을 P0 의 도구 등록부·카드 그리기 등록부·`collab` 클라이언트·`secrets` 저장소에 붙인다. 서버 쪽은 이 기능만의 엔드포인트가 없고, P0 의 CollabHub 문서 종류 표에 `apicol` 검사기 하나, P0 의 카드 종류 표에 `api.*` 스키마 둘만 더한다. 네트워크 작업(전송·실행기·JSON 색인)은 컴포넌트가 소유한 고루틴에서 돌고 화면은 `ui.After` 폴링으로만 결과를 받는다(어떤 Cmd 도 네트워크를 기다리지 않는다).

**Tech Stack:** Go 1.26.6 표준 라이브러리(`net/http`, `net/http/httptrace`, `net/http/cookiejar`, `mime/multipart`, `compress/gzip`, `encoding/json`, `regexp`, `net/netip`) · Bubble Tea v2.1.1 · core `uitest`/`apitest`/`fixtures`/`x/exp/golden` · 서버 TypeScript(Hono 4.13.16, zod 4.6.7, vitest + `@cloudflare/vitest-pool-workers`).

**Spec:** `docs/superpowers/specs/2026-11-09-masil-v0.1.3-design.md` — C3 전체(기능 5), C1.1·C1.2·C1.3·C1.4(공통 바탕), A8(도구 입구), A9(자격증명), 3장(전체 제약), 5장 JX1~JX5·JX16, 8.4 JC14~JC24, "빌더 질문에 대한 결정". 다국어 규칙은 `docs/superpowers/specs/2026-11-09-masil-v0.1.4-i18n-design.md` 6.4·6.5(D8)·6.6·9.3·10.3·15절. 계약: `docs/contract/client-architecture.md`(2.1·2.2·3.2·3.3·5.6·10), `docs/contract/api.md`(2장 카드), 새 `docs/contract/collab.md`(P0 가 만들고 이 계획이 `apicol` 절을 더함).

## Global Constraints

- 툴체인 Go 1.26.6, `CGO_ENABLED=0` 로 macOS·Linux·Windows 크로스 빌드(`make cross`). **새 모듈 0개** — 표준 라이브러리만(JX16). `go.yaml.in/yaml/v3` 는 비시험 코드에서 import 하지 않는다(8.5 Q6 미승인 → **OpenAPI 는 JSON 만**).
- 패키지 이름(설계서 6장 "[빌더 재량]"): 엔진 `internal/apitool`, 변환기 `internal/apitool/convert`, 화면 `internal/ui/apitool`. 설계서 예시 `internal/apitest` 는 쓰지 않는다 — 이미 있는 가짜 masil 서버 `internal/api/apitest` 와 패키지 이름이 겹쳐 같은 파일에서 둘을 import 할 수 없다. 도구 ID `api`, 팔레트 접두사 `api.`, 카탈로그 영역 `apitest.toml`, 카드 type `api.result`·`api.run`, 문서 type `apicol`.
- import 규칙(CA 2.2 에 더함): `internal/apitool/...` → 표준 라이브러리, `internal/secrets`, `internal/collab`(타입만), `internal/config`, `internal/ids`, `internal/textwidth` 만. `internal/api`·`internal/ui/...`·`internal/realtime`·`internal/store` 금지. `internal/api` 는 `internal/apitool` 을 import 하지 않는다(P0 import 그래프 시험 `cmd/masil/importgraph_test.go` 의 접두사 상수에 P4 가 한 줄 더한다 — Task 1). `internal/ui/chat` 은 `internal/ui/apitool` 을 import 하지 않는다(카드는 등록부로만).
- **요청은 내 PC 에서만**: 대상 서버로 가는 HTTP 는 `apitool.Sender` 하나뿐이고 masil API 클라이언트와 섞지 않는다. masil 서버에 대상 URL 값·헤더 값·응답 내용이 가는 경로는 없다(공유 컬렉션 **정의**만 CollabHub 로).
- **비밀값 다섯 겹(JC16)**: ① 값은 `secrets` 저장소에만(파일·공유 문서·오프라인 사본 금지) ② 공유로 나가는 모든 op 는 탐지기 통과 후에만 ③ 비밀 변수마다 보낼 수 있는 호스트 목록, 밖이면 보내기 전에 막음 ④ 카드·기록·내보내기에서 민감 헤더와 비밀 값 문자열은 `•••` ⑤ 로그에는 메서드·호스트·상태·시간만.
- 한도(JC14·C3.7·C3.9): 공유 컬렉션당 요청 1,000 · 요청 본문 64KB(65,536B) · 문서 2MB(2,097,152B) · 카드 데이터 16KB(16,384B) · 화면용 응답 10MB(10,485,760B) · 기록 본문 앞 256KB(262,144B) · 기록 500건 · 가져오기 파일 10MB · 실행기 반복 1..1,000 · 리다이렉트 최대 10 · 타임아웃 기본 30초 · 카드 응답 본문 앞 20줄.
- 동적 변수는 넷만(JC24): `{{$uuid}}`, `{{$timestamp}}`, `{{$isoTimestamp}}`, `{{$randomInt}}`. 스크립트 없음, 검사는 선언형만(JC18). 실행기는 순차·한 번에 하나.
- 문구: 새 패키지 한글 리터럴 0개(P0 래칫 `TestHangulLiteralRatchet`, `internal/i18n/legacy_literals.txt` 에 이 패키지들이 없음 = 0). 문구는 `internal/i18n/locales/ko/apitest.toml`(원본, P0 Task 4 의 빈 영역 파일을 Modify) + `en/apitest.toml` 을 같은 커밋에, zh-Hans 는 P5. 번역하지 않는 것: HTTP 메서드, 상태 문구(`Created`), 헤더 이름, 키 이름, 사용자 라벨. 사람 이름 문구는 D8 `{name}님` 붙여 쓰기(생성기가 `{…} 님` 을 막는다 — 설계서 예시 "hana 님이" 는 `{name}님이` 로 쓴다).
- `no_truncate = true` + `legal = true` 키: `host_block`, `private_target`, `upload_plaintext_note`, `help_terms`, `secret_detected`, `tls_off_warning`. 이 문구는 어떤 크기에서도 잘리지 않고 줄바꿈·스크롤된다.
- 화면에 그리는 남의 글자(응답 본문·헤더, 가져온 파일의 이름, 동료가 쓴 요청 이름·URL, 카드 데이터)는 그리기 전 `textwidth.Sanitize`. HTML 은 글자로만. `View` 는 `textwidth.Fit` 으로 정확히 `size.W × size.H`.
- 시간 지연은 `ui.After` 만(`internal/ui/timers_rule_test.go`). 화면 쪽 Cmd 는 네트워크·파일 대량 읽기를 하지 않는다 — 작업은 컴포넌트 소유 고루틴(`job`), 결과는 `ui.After(ctx, 50*time.Millisecond, jobTickMsg{})` 폴링으로 받는다.
- 기능 플래그(JC21): `features.On("api")`(`MASIL_FEATURES=api`·`all`, 기본 꺼짐) — 도구 `Available`·팔레트 `Available`·카드 `Open` 이 모두 이것을 본다. 꺼져 있으면 허브·팔레트·카드 `enter` 어디에도 안 보인다. 출시 때 한 번에 켜는 것과 목록 골든 갱신은 P0 Task 31.
- 골든: `uitest.Required`(200×60·120×40·80×24·50×20) + 60×24 + 40×14 + 44×24, 테마 기본, 시계 `uitest.Start`. 갱신은 `go test ./internal/ui/apitool -args -update` 또는 `make golden`, 갱신 뒤 사람이 C3.6 시안과 대조. 도구를 안 연 상태의 기존 골든은 하나도 바뀌지 않는다(JX9 예외는 P0 몫).
- 계약은 더하기만, 해당 코드보다 먼저 같은 Task 의 첫 단계에서. 배포·D1·DO 는 이 계획 범위 밖(오너 건별 승인). 서버 시험은 로컬 vitest 만.
- 코드·주석·커밋 메시지는 영어, 계획 문구는 한국어. 커밋 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. 공유 요청이 비밀 변수와 함께 허용 호스트로 갔는데 그 서버가 **다른 호스트로 리다이렉트**한다 → `net/http` 는 `Authorization` 만 떼고 `X-Api-Key`·쿼리 비밀은 그대로 따라 보낸다. 사람은 "허용한 호스트에만 간다"고 기대한다 → 리다이렉트를 멈추고 3xx 응답과 안내를 보인다 (Task 4 `TestRedirectToUnlistedHostStopsWithSecret`).
2. 동료가 고친 요청의 호스트가 **이름은 공용인데 사설 IP 로 풀리는** 경우(`internal.example` → 10.0.0.5, `127.0.0.1.nip.io`) → 글자만 보는 검사는 놓친다. 연결 직전 해석된 IP 로 확인을 묻는다 (Task 4 `TestForeignHostnameResolvingToLoopbackAsks`).
3. 비밀 변수가 **헤더가 아니라 URL 쿼리·경로**(`?api_key={{key}}`)에 들어간 요청 → 기록의 "치환 후 URL"·카드의 "호스트 보이기"에 값이 그대로 남으면 안 된다 (Task 7 `TestHistoryMasksSecretInExpandedURL`, Task 20 `TestResultCardHostShownNonSecretOnly`).
4. **줄바꿈 없는 10MB JSON 한 줄**(minified)·10MB 한 줄 글자 → 나무 색인은 고루틴에서, 그리기는 보이는 줄만이어야 화면이 멈추지 않는다 (Task 15 `TestMinifiedHugeJSONWindowed`).
5. 동료가 공유 환경에서 내 **비밀 변수의 "비밀" 표시를 끄거나 값을 채워 넣는** 경우 → 내 저장소 값이 문서로 올라가거나, 동료가 넣은 공유 값이 내 비밀 대신 쓰이면 안 된다 (Task 18 `TestPeerUnsetsSecretFlagKeepsMyValueLocal`).
